# Engineering Decisions (ADR)
- **ADR-001: Workspaces over Pages.** Rationale: Synapse is an operating system, not a website. Context must persist.
- **ADR-002: Legacy Migration Area.** Rationale: Prevents destructive deletions before new implementations are stable.
- **ADR-003: Strict Token System.** Rationale: Ensures enterprise UI consistency.
