# Design System Contract
- **Typography:** Geist Sans (14px UI), Geist Mono (data/metrics).
- **Spacing:** Base 4pt scale.
- **Colors:** Deep enterprise tokens (`bg-background-dark`, `border-subtle`).
- **Interaction:** No generic shadows. Focus states must use high-contrast 2px ring.
