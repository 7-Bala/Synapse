# Workspace Specification
Workspaces replace pages. A Workspace is a persistent operational workflow.
- **Context Persistence:** Navigating between workspaces does not clear the active state.
- **Layout:** Standardized via `WorkspaceShell` with a `WorkspaceDock` for tool switching.
